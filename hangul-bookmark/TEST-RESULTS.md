**2022 이후는 지원 목표이며 모든 이후 버전의 시험 완료를 뜻하지 않습니다.**

## 한글 파일 작성

- HWP/HWPX에서 파일 열기 → 책갈피 이동 → 본문과 분수 수식 생성 → 저장 → 재열기 확인.
- 일반 본문·표 셀·범위 책갈피에서 글·분수·첨자·근호·합·적분·행렬·그림 삽입 확인.
- 반복 삽입의 새 내용 순서와 책갈피 시작 유지, 범위 책갈피의 기존 글 보존 확인.
- 기존 표의 행·열·셀 너비·병합 구조 비교 통과.
- 별도 수정본 생성·후속 저장·중복 요청 방지·원본 해시 보존 확인.
- 수식 개체의 네이티브 SCRIPT 보존 및 텍스트·수식·그림 순서 검사.
- 페이지 이미지로 주요 수식과 그림 표시 검토. 표 셀 그림 너비 제한 확인.

## 열린 문서 직접 작성 (0.2.0)

HWP/HWPX × 본문·표 셀·범위 책갈피의 6개 임시 문서 시나리오를 확인했습니다. 선택한 창에 본문과 분수 수식을 넣고 저장 전 사용자 변경, 다른 창, 원본 파일 해시를 보존했습니다. 연결 종료 후 사용자 창이 유지되는 것도 확인했습니다.

설치된 MCP 연결로 HWP와 HWPX 창을 선택해 본문·수식을 작성하고 같은 요청 ID를 재전송했을 때 중복 삽입되지 않는 것을 확인했습니다. 실제 한글에서 입력 위치의 본문 글자 크기와 수식 기본 크기를 비교했습니다.

## 도구 연결 수정 (0.2.1)

- Codex가 절대 실행 파일 경로를 거부해 도구 등록을 생략하는 오류를 확인했습니다.
- 실행 파일 이름과 PATH 설정을 사용하고 설치 패키지의 `./launch.py`를 실행하도록 변경했습니다.
- 실제 `codex mcp list --json`에서 연결 활성화와 설치 폴더의 실행 위치를 확인했습니다.
- 설치본의 다섯 도구 목록과 HWP/HWPX 연결 검사를 통과했습니다.
- 다른 작업 폴더에서 로컬 MCP 브리지로 환경 검사 및 `E=mc^2` 변환을 확인했습니다. 사용자 문서를 수정한 시험은 아닙니다.
- 새 대화에서 모델에 도구가 실제 노출되는 최종 시험은 앱 연결 재시작 후 확인이 필요합니다.

## 자동 검사

버전 0.2.1의 기존 자동 검사: **36 passed**.

LaTeX 변환과 지원하지 않는 표현 거부, 이미지 crop 검사, 원문 순서, 불확실한 입력 거부, 원본 보존, 중복 요청과 요청 ID 충돌, 파일 이름 충돌·외부 변경·없는 책갈피·선택 취소·잠금 처리, 실패 시 마지막 성공본 유지, 열린 창 수명과 시간 초과 후 추가 입력 중단을 검사했습니다. 오류 처리의 일부 검사는 가짜 COM 실행기를 이용한 오류 주입입니다. 스킬 형식 검사도 통과했습니다.

## 남은 확인 항목

- 한글 2024 및 이후 버전 실제 시험.
- 수식 개체를 마우스로 더블클릭하는 편집 UI 시험.
- 여러 창 선택과 파일·책갈피 선택 창의 수동 UI 시험.
- 실제 흐릿한 이미지와 그래프 혼합 이미지에 대한 Codex 판독 정확성.
- 고정 높이 셀의 실제 잘림과 복잡한 페이지 배치.
- 열린 창 방식의 새 그림 가져오기 전체 경로.
- 모든 PC의 보안 모듈 등록 및 로드. 이 시험 PC에서는 한글이 실제로 읽는 현재 사용자 키에 재등록한 뒤 파일 승인 창 없이 시험을 통과했습니다.

입력 중 오류가 난 열린 문서는 부분 입력 가능성을 반환하며 자동 복원·재삽입을 보장하지 않습니다. 이미 진행 중인 COM 호출은 즉시 취소할 수 없습니다. 파일 교체 단계의 짧은 외부 변경 경쟁 구간도 남아 있습니다.

개인 경로와 문서 정보를 포함하는 원시 시험 보고서는 공개 저장소에 포함하지 않습니다.


## 첨자 뒤 공백 수정 (0.2.2, 2026-10-15)

- 위첨자/아래첨자 묶음 뒤에 공백 한 칸을 자동 삽입합니다. LaTeX 변환과 한글 스크립트 직접 입력 모두에 적용합니다.
- 예: `2^{2k}+1` → `2^{2k} +1`, `2^2k+1` → `2^2k +1`, `x_{i+1}+y` → `x_{i+1} +y`.
- 중첩·연속 첨자, 이미 있는 뒤 공백, 큰따옴표 안의 문자 그대로의 ^/_ 및 재검사 시 공백 중복 방지를 검사했습니다.
- 자동 검사 **60 passed**. 실제 임시 HWP/HWPX 각각에 예제 4개를 생성·저장·재열기한 뒤 SCRIPT와 공백이 정확히 보존됨을 확인했습니다.
- 이 시험은 사용자 문서를 수정하지 않았으며, 전체 렌더링·더블클릭 편집 UI 시험을 의미하지 않습니다.
