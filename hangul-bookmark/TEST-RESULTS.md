# 0.3.0 시험 결과 — 2026-10-16

- Windows 한글 2022 / COM·실행 파일 12.0.0.535 / 32비트.

- 한글 2024 및 이후 빌드는 미검증입니다. 2022 이후는 지원 목표이며 모든 버전 시험 완료를 뜻하지 않습니다.

**104 passed.** 기존 60개 검사와 함께 다음을 확인했습니다.

- 문단·표·중첩 표의 구조, 원문 위치, 중복 문장 검색과 UTF-16 위치.
- 오래된 분석·대상 거부, 수정 전 원문 대조, 겹치는 변경과 부분 수식 선택 거부.
- 글꼴·크기 이외의 서식 보존, 수식 서식 변경 시 스크립트 공백까지 보존.
- 파일 원본 보존·이름 충돌·미리보기·중복 요청·완료 기록 복구.
- 열린 창의 알려진 실패 재시도와 불명확한 실패/시간 초과 후 재삽입 차단.
- 큰 문단과 긴 수식의 분할 조회, 검색 결과 페이지 처리, 선택 범위와 셀 그룹.
- 서로 다른 연결 프로세스의 COM 생성 캐시 분리와 종료 시 정리.

오류 처리의 일부는 가짜 COM 실행기를 이용한 오류 주입 검사이며, 모든 한글 오류나 실제 디스크 장애 조합을 재현한 것은 아닙니다.

## 실제 한글 시험

- HWP/HWPX 각각에서 파일 수정본과 열린 창 수정의 4개 종합 경로를 통과했습니다.
- 책갈피 없는 문장 교체·기존 수식 교체·본문/수식 크기 변경·본문 글꼴 변경을 수행했습니다.
- 파일 방식의 원본 해시, 수정본 저장·재열기, 요청 밖 본문·수식·표 구조·서식 보존을 검사했습니다.
- 열린 창에서 저장 전 사용자 변경·원본 디스크 파일·다른 창을 보존했습니다. 동일 요청 재전송과 연결 종료 후 창 유지도 확인했습니다.
- 본문·표 셀·중첩 표, 글자 선택과 수식 개체 선택, 여러 셀의 선택 보관·읽기 후 복원을 확인했습니다.
- 빈 문단 서식, 혼합된 굵게·색 서식을 포함한 문장 교체, 명시한 제목 경계의 제외, 기존 수식 글꼴 유지와 HancomEQN 지정, 각주 제외·내용 보존을 확인했습니다.
- 설치되지 않은 글꼴은 적용 전에 거부했습니다.
- 점·범위 책갈피를 새 편집 대상으로 찾고 서식을 변경하는 4개 조합을 확인했습니다. 문단 안의 글자 전체만 지우는 경우에도 문단 수와 기본 서식을 유지했습니다.
- 기존 삽입 경로는 HWP/HWPX × 본문·표·범위 책갈피 6개와 파일 트랜잭션 2개, 총 8개 시나리오를 통과했습니다. 수식·행렬·그림·반복 삽입을 포함합니다.

## 설치본 MCP 연결

설치된 0.3.0에 새 stdio MCP 클라이언트로 연결해 도구 8개 노출을 확인했습니다. 문서 선택 → 읽기 → 중복 문장의 두 번째 위치 검색 → 문장·수식·서식 수정 → 재전송 방지를 실제 도구 호출로 확인했습니다.

열린 창의 보관한 선택 영역과 다중 셀 선택에도 같은 경로를 적용했고, 자동 저장하지 않았으며 디스크 파일을 보존했습니다. 환경 검사에는 HWP/HWPX의 새 편집 smoke 시험도 포함됩니다. Codex 자체 연결 목록에서 설치본 활성화와 실행 경로를 확인했습니다.

이는 새 MCP 연결 시험입니다. 사용자가 Codex를 재시작한 뒤 새 대화에서 자연어 요청을 수행하는 UI 시험은 별도로 남아 있습니다.

## 수학 검토 예제와 제한

2+2=5, sqrt(9)=±3의 수정 예제와 올바른 2+2=4를 유지하는 예제로 수식 읽기·교체 흐름을 확인했습니다. 이는 판정한 예제를 적용하는 경로의 검증이며, Codex의 일반적인 수학 검토 정확도를 수치로 측정하거나 모든 오류 탐지를 보장하지 않습니다.

머리말·꼬리말·각주·미주·글상자 내부 수정, 그림 속 내용의 OCR/교체, 문단 수·순서 및 표 구조 변경은 지원 범위 밖입니다. 수식 더블클릭 편집 UI, 여러 창 선택 대화상자의 모든 클릭 경로, 모든 글꼴·문서 조합의 표시 품질과 고정 높이 셀의 실제 잘림은 확인이 필요합니다.

네이티브 시험은 사용자 원본 대신 임시 문서와 명시적으로 소유한 시험 창을 사용했습니다. 개인 경로와 문서 내용을 담는 원시 보고서는 공개 저장소와 공유 패키지에 포함하지 않습니다.
