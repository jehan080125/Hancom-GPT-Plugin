name: hangul-bookmark
description: Windows 한글 2022 이후의 hwp/hwpx 파일 또는 현재 열린 한글 문서의 책갈피에 본문·편집 가능한 수식·그림을 작성한다. 열린 창 직접 작성과 파일 수정본 작성을 지원한다.
---

사용자의 문구·수식 의미·순서를 그대로 보존한다. 요약, 풀이 추가, 문장 교정은 요청 없이는 하지 않는다.

전용 MCP 도구가 목록에 없으면 연결 불가로 단정하지 말고 [로컬 연결 절차](references/local-connection.md)를 읽는다. 로컬 실행 도구가 제공되고 설치된 연결 설정이 유효하면 포함된 MCP 브리지로 같은 다섯 도구를 호출할 수 있다. 실제 연결 실패나 실행 권한이 없는 경우에만 작업을 중단하고 확인된 오류를 알린다.

처음 사용하거나 연결이 바뀌면 check_environment를 run_smoke=true로 호출한다. 실패하면 문서 작성하지 않는다. 결과의 실제 버전·빌드와 시험 결과만 설명한다. 2022 이후 전체를 시험 완료했다고 하지 않는다.

파일 선택 요청에는 select_document를 호출해 PC 선택 창을 연다. 사용자가 명시한 로컬 경로도 허용한다. select_bookmark로 정확한 이름 또는 PC 목록 창에서 위치를 확정한다. 파일 이름, 책갈피, 저장 예정 경로를 알린다. 취소는 기존 대상 변경 없이 끝난다.

“지금 열린 문서에 작성” 요청에는 select_document(mode="open")를 사용한다. 한 문서면 그 문서를 선택하고 여러 문서면 PC 목록에서 사용자가 고른다. 대화에서 대상을 지정하려면 mode="open", list_only=true로 목록과 window_id를 얻은 뒤 정확한 window_id로 선택한다. 제목만 보고 임의로 다른 창을 선택하지 않는다. select_bookmark로 위치를 정하고 선택한 문서 이름과 책갈피를 알린다. 열린 창 방식은 저장 전 사용자 변경을 포함한 현재 내용을 사용하고, 자동 저장·수정본으로 전환·창 닫기를 하지 않는다. 저장은 사용자가 직접 한다.

내용은 [블록 규격](references/blocks.md)에 따라 원문 순서로 구성한다. LaTeX에는 format=latex를 쓴다. 직접 한글 스크립트를 전달할 때 [수식 예제](references/equations.md)를 참고한다. 변환기가 거부한 표현을 임의로 단순화하거나 삭제하지 않는다.

첨부 이미지는 시각적으로 읽어 본문과 수식을 편집 가능한 블록으로 전사한다. 그래프·기하 도형만 원본 이미지의 픽셀 영역으로 잘라 image 블록을 작성한다. 서버가 OCR을 해주는 것으로 설명하지 않는다. 첨부 파일에 로컬 경로가 없으면 접근 가능한 원본 파일이 필요하다. 흐릿한 기호, 읽을 수 없는 글자는 해당 부분만 질문한다. 내용 추측 금지. 판독되지 않은 부분을 남긴 채 부분 성공 저장하지 않는다.

사용자가 미리보기를 요청한 경우만 preview_content 결과를 보여준다. 그렇지 않으면 작성 요청이 승인이다. insert_content에 고유 request_id를 한 번 생성해서 호출하고, 동일 요청 재시도에는 같은 ID와 같은 블록을 재사용한다. 새로운 요청은 새 ID를 쓴다. 요청 결과 ok=false는 실패이며 저장 성공으로 보고하지 않는다.

성공하면 output 경로, 본문 블록·문단 구분·수식·그림 수와 warnings를 알린다. 후속 작업은 같은 document_id로 계속하여 수정본을 이어서 저장한다. 반복 삽입은 책갈피 시작에 하므로 새 내용이 앞에 온다. 오류·외부 변경 시 새 파일 선택으로 대상을 재확정한다.

mode="open" 성공은 saved=false이다. “열린 창에 작성 완료, 아직 저장하지 않음”과 개수를 알린다. output=null을 저장 실패나 저장된 결과 파일로 해석하지 않는다. backup은 작성 전의 복원용 HWP 사본이며 작성 결과 파일이 아니다. 열린 문서가 닫히거나 다른 파일로 바뀌면 다시 선택한다. LIVE_RECOVERY_REQUIRED/시간 초과에서는 일부 입력 가능성을 알리고 같은 내용을 새 요청 ID로 자동 재삽입하지 않는다. 작업 전 사본과 현재 창을 확인해야 한다. 사용자의 이전 입력과 실행 취소가 합쳐질 수 있으므로 임의의 반복 Undo나 문서 전체 교체로 복원하지 않는다.

본문 및 표 셀만 지원한다. 글상자·머리말·꼬리말, PDF 입력, 기존 내용 교체, 그래프의 도형 재구성은 지원하지 않는다. 표 고정 높이의 실제 잘림, 렌더링 품질, 수식 더블클릭 편집은 반환된 자동 검사만으로 확인됐다고 말하지 않는다.
