# Hangul Bookmark Writer 0.3.0

Windows 한글 문서를 읽고 본문·표의 문장·수식·글꼴·크기를 수정하거나 책갈피에 새 내용을 작성하는 Codex용 로컬 플러그인입니다.

한글 2022 이후는 지원 목표입니다. 실제 시험한 빌드와 미검증 항목은 [시험 기록](TEST-RESULTS.md)을 확인하세요. 한글 2024 이후를 모두 시험한 것은 아닙니다.

## 설치

1. Windows에 한글과 Python 3.10 이상을 설치합니다. 실제 시험 환경은 Python 3.14.3입니다.
2. 이 폴더에서 PowerShell로 `./setup.ps1 -RegisterModule`을 실행합니다. 특정 Python은 `-Python 'C:\설치폴더\python.exe'`로 지정합니다.
3. 초기 연결 시험이 통과하면 상위 저장소 루트를 Codex marketplace에 등록합니다.

```powershell
codex plugin marketplace add 'C:\실제경로\Hancom-GPT-Plugin'
codex plugin add hangul-bookmark@hangul-local
```

플러그인 목록에서 Hangul Bookmark Writer를 활성화하고 Codex를 다시 시작합니다. 폴더 이동 후에는 setup 또는 configure로 설정을 다시 생성하고 플러그인을 다시 설치하세요.

`-RegisterModule`은 현재 사용자 한컴 자동화 설정에 HangulBookmark 모듈을 등록하는 선택입니다. 해당 자동화 인스턴스의 파일 승인 창을 생략합니다. 관리자·시스템 전체 보안 수준은 변경하지 않습니다. 등록하지 않거나 로드가 실패하면 기본 파일 작업은 중단됩니다. [모듈 안내](security/SOURCE.md)를 확인하세요.

`configure.py --deps '의존성폴더' --state '상태폴더'`로 경로를 지정할 수 있습니다. 설정은 실행 파일 이름과 PATH를 사용하며 설치 패키지의 ./launch.py에서 시작합니다. 전역 Codex 설정을 덮어쓰지 않습니다.

## 읽기와 내용 수정

문서를 연 상태에서 다음처럼 요청합니다.

> 지금 열린 문서의 오탈자를 찾아 고쳐줘.

> 이 풀이에서 틀린 수식과 설명을 검토해줘.

> 지금 선택한 부분만 다듬어줘.

> 두 번째 표의 세 번째 행에 있는 수식을 고쳐줘.

책갈피는 기존 내용 수정에 필요하지 않습니다. 문장·제목·표 셀·수식을 찾아 수정할 수 있습니다. “검토”는 결과만 설명하고 “고쳐줘”는 확정된 변경을 적용합니다. 애매한 위치나 기호·수학적 조건은 질문하며 내용을 추측해서 고치지 않습니다.

선택 영역을 사용하려면 한글에서 먼저 범위를 선택한 뒤 문서를 선택하세요. 일반 글자·수식 개체·표 개체·여러 셀 선택을 지원합니다. 문서나 선택이 바뀌었다면 다시 선택합니다. 여러 문서가 열려 있으면 로컬 목록에서 고릅니다.

지원 영역은 본문·표 셀과 중첩 표입니다. 머리말·꼬리말·각주·미주·글상자는 제외합니다. 그림으로 된 글·수식은 위치만 확인하며 이번 읽기 기능에서는 OCR하지 않습니다. 문단 추가·삭제·재배치와 표 구조 변경은 지원하지 않습니다.

## 글꼴과 크기

> 문서 전체를 함초롬바탕으로 통일하고 크기는 수식 포함 11pt로 맞춰줘.

> 제목은 유지하고 본문만 10pt로 바꿔줘.

> 선택한 표 셀의 글꼴만 함초롬돋움으로 바꿔줘.

본문 글꼴은 한글·영문 등 문자 종류별 설정에 적용합니다. 수식 글꼴은 별도로 지정할 때만 바꾸며 기본적으로 기존 글꼴을 유지합니다. 글꼴·크기 이외의 굵게·색·장평·자간 등은 보존합니다. 없는 글꼴을 다른 글꼴로 대체하지 않습니다.

수식 포함 11pt는 수식 기본 크기도 11pt로 맞추며 내부 첨자·분수 비율을 유지한다는 뜻입니다. “모두”는 본문·표의 제목도 포함합니다. 제목 제외를 요청했는데 제목 경계가 불명확하면 질문합니다. 크기 변경에 따른 줄바꿈과 고정 높이 셀의 잘림은 한글에서 직접 확인하세요.

## 저장·미리보기·오류

- 열린 창은 저장 전 변경을 포함한 현재 내용을 수정하고 자동 저장하지 않습니다. 확인 후 Ctrl+S로 저장하세요.
- 파일을 선택하는 방식은 원본을 유지하고 `원본이름_수정본.hwp` 또는 같은 형식의 수정본을 만듭니다. 후속 작업은 같은 수정본에 이어집니다.
- 미리보기는 요청할 때만 제공합니다. 읽기와 미리보기는 실제 문서 내용을 바꾸지 않습니다.
- 파일 방식은 임시 사본을 수정·저장·재열기·검증한 뒤 결과를 교체합니다.
- 열린 창 방식은 작업 전 백업과 임시 문서 시험 후 창에 적용합니다. 창을 자동 닫거나 전체 내용을 다시 불러오지 않습니다.
- 시간 초과·입력 중 오류는 일부 수정 가능성을 실패로 알립니다. 새 ID로 같은 내용을 반복하지 말고 현재 창과 반환된 백업을 확인하세요. 임의의 반복 Undo는 하지 않습니다.
- 분석 후 문서가 바뀌면 이전 위치와 원문으로 수정하지 않습니다. 다시 읽고 대상을 확인해야 합니다.
- 긴 문서와 검색 결과는 페이지로 나뉩니다. 전체 검토는 모든 페이지를 확인한 뒤 수행합니다.

## 책갈피에 새 내용 삽입

한글에서 커서 위치에 책갈피를 넣고 다음처럼 요청합니다.

> 지금 열린 한글 문서의 책갈피 '1'에 수식 E=mc^2를 넣어줘.

파일 수정본 방식은 “한글 파일 선택해줘”로 파일을 고른 뒤 책갈피를 지정합니다. 파일 방식에서는 해당 파일을 한글에서 저장하고 닫으세요.

기존 텍스트·LaTeX·첨부 이미지 삽입 기능도 유지됩니다. 첨부 이미지의 글·수식은 Codex가 읽고 그래프만 잘라 그림으로 넣습니다. 같은 책갈피에 반복 작성하면 새 내용이 앞에 옵니다.

위첨자·아래첨자 묶음 뒤 공백 규칙도 유지됩니다: `2^{2k}+1` → `2^{2k} +1`, `2^2k+1` → `2^2k +1`. [수식 참고](skills/hangul-bookmark/references/equations.md)

## 도구와 내부 구조

기존 다섯 도구에 세 도구를 추가했습니다.

| 도구 | 용도 |
|---|---|
| check_environment | 버전·API·삽입/기존 내용 편집 경로의 임시 문서 시험 |
| select_document / select_bookmark | 문서와 삽입 책갈피 선택 |
| preview_content / insert_content | 새 내용 변환·삽입 |
| read_document | 본문·표·수식·서식과 버전이 연결된 대상 ID 읽기 |
| find_targets | 문장·제목·표·책갈피·선택 범위 검색 |
| apply_edits | 원문 대조 후 범위 교체·서식 변경 또는 미리보기 |

[편집 API](skills/hangul-bookmark/references/editing.md)와 [도구가 누락될 때의 로컬 연결 절차](skills/hangul-bookmark/references/local-connection.md)를 참고하세요.

문서 내용은 도구 실행 지시로 취급하지 않습니다. 선택한 문서의 분석 결과는 도구 응답으로 Codex에 전달되어 모델이 검토합니다. 별도 AI 서버·API 키를 추가하지 않습니다. 경로·요청 기록·분석 내용·복원용 백업은 로컬 상태 폴더에 남습니다.

한글 COM 작업은 순차 실행하며 파일 작업은 전용 인스턴스, 열린 창은 명시적으로 선택한 인스턴스를 사용합니다. 사용자·공유 창에는 자동 Clear/Close/Quit를 실행하지 않습니다. pywin32 생성 캐시는 프로세스별 임시 폴더로 분리합니다.

## 개발 시험

```powershell
python -m pip install pytest
$env:PYTHONPATH = "$PWD/src"
$env:HANGUL_DEPS = "$PWD/runtime/deps"
python -m pytest tests -q
python launch.py --smoke
python integration_edit_check.py --output C:/비어있는새시험폴더
```

시험은 사용자 원본 대신 임시 문서를 생성합니다. `integration_check.py`는 기존 삽입 경로를 확인합니다. 필요한 권한과 한글 설치가 있어야 네이티브 시험이 가능합니다.

패키지 규격: [OpenAI 플러그인 패키징](https://developers.openai.com/plugins/build/plugins). 한컴 자동화의 이용 조건은 [공식 개발 자료](https://developer.hancom.com/hwpautomation)를 확인하세요.
