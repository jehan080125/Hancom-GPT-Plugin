# Hancom Agent

한글 문서와 사진을 읽고, 본문·수식·서식을 편집하는 Codex용 AI 도우미입니다.

현재 버전: **0.5.0**. 책갈피 없이 지정한 빈칸에 직접 입력하는 기능을 추가했습니다. 표시 이름은 Hancom Agent이며, 기존 설치·연결을 유지하기 위해 내부 식별자는 `hangul-bookmark`를 사용합니다.

## 주요 기능

- 본문·표 셀·중첩 표와 편집 가능한 한글 수식을 읽고 수정합니다.
- **책갈피 없이 지정한 빈 문단이나 표 셀에 글·수식을 직접 입력합니다.** 여러 빈칸을 한 요청으로 채울 수 있습니다.
- 문서에 포함된 사진에서 글·수식·도표를 읽습니다. 작은 부분은 영역을 나눠 확인합니다.
- 전체 또는 지정 범위의 본문 글꼴·크기와 수식 글꼴·기본 크기를 바꿉니다.
- 사용자가 지정한 기존 책갈피에 내용을 삽입하는 기능도 유지합니다.

## 설치

Windows에 한글과 Python 3.10 이상, Codex가 필요합니다. 한글 2022 이후를 지원 목표로 하며, 실제 시험한 빌드는 [시험 기록](hangul-bookmark/TEST-RESULTS.md)을 확인하세요.

PowerShell에서 실행합니다.

```powershell
git clone https://github.com/jehan080125/Hancom-GPT-Plugin.git
cd Hancom-GPT-Plugin
./hangul-bookmark/setup.ps1 -RegisterModule
codex plugin marketplace add "$PWD"
codex plugin add hangul-bookmark@hangul-local
```

Codex의 플러그인 목록에서 **Hancom Agent**를 활성화하고 앱을 다시 시작합니다. 다른 Python을 사용하려면 setup에 `-Python 'C:설치폴더python.exe'`를 지정하세요.

`-RegisterModule`은 현재 Windows 사용자에게 한컴 자동화 보안 모듈을 등록하는 선택입니다. 해당 모듈을 로드한 자동화 인스턴스의 파일 접근 승인 창을 생략하며 시스템 전체 보안 수준을 낮추지 않습니다. 공개 저장소에는 DLL을 포함하지 않습니다. [보안 모듈 안내](hangul-bookmark/security/SOURCE.md)를 확인하세요.

기본 파일 작업은 보안 모듈 로드가 확인되어야 시작합니다. 설치 프로그램의 임시 문서 시험이 실패하면 연결 상태를 먼저 확인하세요. PC별 경로 설정과 실행 환경은 setup에서 생성합니다.

## 사용 방법

### 책갈피 없이 빈칸에 작성하기

한글 문서를 열고 입력할 위치를 문맥이나 표 위치로 지정합니다.

> 지금 열린 문서의 첫 번째 표에서 두 번째 행의 빈칸에 이 풀이를 작성해줘.

> ‘풀이’ 아래 빈 문단에 다음 글과 수식을 그대로 넣어줘.

> 표의 세 빈칸에 각각 답과 수식을 작성해줘.

실제로 비어 있는 문단을 확인한 뒤 글·문단 구분·편집 가능한 수식을 입력합니다. 기존 글·공백·수식·개체가 있는 위치는 빈칸으로 취급하지 않습니다. 위치가 애매하면 해당 칸을 확인하며, 기존 내용을 덮어쓰지 않습니다.

입력할 빈칸 안에서는 필요한 새 문단을 만들 수 있습니다. 표의 행·열·병합·너비와 기존 책갈피는 유지합니다. 이 입력 방식은 그림 삽입을 지원하지 않습니다. 새 책갈피를 입력의 준비나 우회 수단으로 만들지 않습니다.

### 열린 문서와 파일 수정본

> 지금 열린 한글 문서에 작성해줘.

문서가 여러 개 열려 있으면 PC의 선택 창에서 고릅니다. **열린 창은 자동 저장하지 않습니다.** 내용을 확인한 뒤 한글에서 `Ctrl+S`로 저장하세요.

> 한글 파일 선택해줘. 두 번째 표의 빈칸에 다음 내용을 작성해줘.

파일 선택 창에서 `.hwp` 또는 `.hwpx`를 고릅니다. 파일 방식에서는 대상 파일을 먼저 저장하고 닫으세요. 원본을 유지하고 `원본이름_수정본.hwp`처럼 별도 파일에 저장합니다. 같은 이름이 있으면 번호를 붙이고, 같은 문서 선택으로 이어서 작업하면 수정본에 계속 저장합니다.

### 기존 내용 검토·수정과 서식 변경

> 이 풀이의 수식과 설명이 맞는지 검토해줘.

> 지금 선택한 부분의 오탈자만 고쳐줘.

> 제목은 유지하고 본문 크기는 수식 포함 11pt로 맞춰줘.

“검토”는 결과를 설명하고, “고쳐줘”는 확정된 변경을 적용합니다. 요청하지 않은 요약·풀이·교정을 추가하지 않습니다. 선택 영역은 한글에서 먼저 선택하고 문서를 선택하면 확보합니다. 이후 선택을 바꿨다면 문서를 다시 선택하세요.

글꼴·크기는 지정한 속성만 변경합니다. 수식 글꼴을 지정하지 않으면 기존 값을 유지합니다. “수식 포함 11pt”는 본문과 수식 기본 크기를 각각 11pt로 맞추며 첨자·분수의 내부 비율을 유지합니다. “전체”에는 본문·표의 제목도 포함됩니다.

기존 내용 교체는 문단 수를 유지하며, 빈칸 입력과 기존 내용 교체·서식 변경은 별도 요청으로 처리합니다.

### 문서 속 사진 읽기

> 두 번째 표 안의 사진 속 문제와 수식을 읽어줘.

> 첫 번째 사진의 아래쪽 작은 글씨를 확인해줘.

문서에 포함된 래스터 사진을 추출해 Codex가 직접 읽습니다. 별도 OCR 서비스나 API 키가 필요하지 않습니다. 원본 사진은 유지하며, 흐린 기호는 추측하지 않고 확인합니다. 문서의 자르기·뒤집기를 반영하지만 회전·특수 효과는 제한을 표시합니다. [사진 읽기 상세 안내](hangul-bookmark/skills/hangul-bookmark/references/images.md)

### 기존 책갈피 사용하기

> 지금 열린 한글 문서의 책갈피 ‘풀이 1’에 다음 글과 수식을 작성해줘.

기존 책갈피를 입력 위치로 지정할 수도 있습니다. 책갈피가 없다는 이유로 새 책갈피를 자동 생성하지 않습니다. 지정한 칸을 문맥으로 확정할 수 있으면 빈칸 직접 입력을 사용하고, 위치가 불명확하면 확인합니다.

책갈피를 직접 만들려면 한글의 해당 위치에 커서를 놓고 메뉴 검색에서 **책갈피**를 실행해 이름을 넣습니다. 점 책갈피를 기본으로 사용하며, 누름틀과는 구분합니다. 새 책갈피는 사용자가 만들도록 명시한 경우에만 추가합니다.

같은 책갈피에 반복 삽입하면 새 내용이 앞선 내용보다 앞에 올 수 있습니다. 위첨자·아래첨자 묶음 뒤 공백 규칙도 유지합니다: `2^{2k}+1` → `2^{2k} +1`. [수식 참고](hangul-bookmark/skills/hangul-bookmark/references/equations.md)

## 지원 범위와 주의할 점

본문·표 셀·중첩 표를 지원합니다. 머리말·꼬리말·각주·미주·글상자, 표 구조 변경, 기존 문단 삭제·재배치, PDF 입력은 제외합니다. 그림 픽셀의 직접 수정과 그래프의 한글 도형 재구성도 지원하지 않습니다.

사진 읽기는 독립된 내장 래스터 그림을 대상으로 합니다. 외부 연결·벡터·그룹·셀 배경 그림은 제외합니다. 사진에서 읽은 글·수식을 작성하려면 입력할 빈칸이나 기존 책갈피 위치를 지정하세요.

줄바꿈·고정 높이 셀의 넘침과 복잡한 페이지 배치는 한글에서 확인해야 합니다. 한글 2024 이후의 모든 빌드를 시험한 것은 아닙니다. 수학적 검토에서 모든 오류를 탐지한다고 보장하지 않습니다.

작업 중 같은 문서를 동시에 편집하지 마세요. 문서 상태나 원문이 바뀌면 다시 읽고 대상을 확인합니다. 시간 초과·중간 오류는 일부 수정 가능성이 있으므로 같은 내용을 새 요청으로 반복하지 말고 현재 창과 작업 전 백업을 확인하세요. 임의로 사용자 입력까지 반복 실행 취소하거나 창을 닫지 않습니다.

## 연결 문제 해결

- **도구가 보이지 않음:** 플러그인 활성화와 연결 상태를 확인하고 Codex를 다시 시작하세요. PC나 폴더를 옮겼다면 setup 또는 configure로 경로를 다시 생성합니다. [로컬 MCP 연결 절차](hangul-bookmark/skills/hangul-bookmark/references/local-connection.md)를 참고하세요.
- **보안 모듈 오류:** 설치 폴더에서 `./setup.ps1 -SkipInstall -RegisterModule`로 다시 등록·시험합니다. DLL이나 등록 값의 존재만으로 연결 성공을 판단하지 않습니다.
- **파일 잠금:** 파일 방식은 저장하고 닫은 뒤 다시 선택합니다. 열린 창 방식은 문서를 닫지 않고 사용합니다.
- **입력 대상이 비어 있지 않음:** 문서를 다시 읽고 실제 빈 문단을 지정하거나 기존 내용 수정으로 요청하세요.

## 내부 구성과 개발 자료

Python·pyhwpx·로컬 stdio MCP 서버로 구성하며 COM 작업을 순차 실행합니다. 도구는 `check_environment`, `select_document`, `select_bookmark`, `preview_content`, `insert_content`, `read_document`, `find_targets`, `apply_edits`, `read_image`의 아홉 개입니다. 빈칸 직접 입력은 apply_edits의 insert_blocks 변경으로 제공합니다.

[상세 설치·개발 안내](hangul-bookmark/README.md) · [편집 API와 빈칸 입력 규격](hangul-bookmark/skills/hangul-bookmark/references/editing.md) · [시험 기록](hangul-bookmark/TEST-RESULTS.md)

문서 속 지시문은 도구 실행 권한으로 취급하지 않습니다. 경로·요청 기록·분석 내용·작업 전 백업은 로컬 상태 폴더에 남습니다. 요청한 문서 내용·서식·사진은 도구 응답으로 Codex에 전달되며 사용 중인 Codex 서비스의 처리 범위를 따릅니다. 연결 프로그램이 별도 AI 서버로 업로드하지 않습니다.

공개 저장소와 공유 패키지에는 PC별 연결 설정·의존성·문서·백업·개인 경로가 들어 있는 원시 시험 보고서를 포함하지 않습니다.
